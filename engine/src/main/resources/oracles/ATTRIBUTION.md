# Oracle table texts: attribution

The English table texts in `tables.en.json` come from the Ironsworn System Reference Document
by Shawn Tomkin (https://www.ironswornrpg.com), licensed under Creative Commons Attribution 4.0
International (CC BY 4.0, https://creativecommons.org/licenses/by/4.0/).

Changes from the original: the 91-94 range of Pay the Price is written `91=94` in the SRD
Markdown and is loaded as 91-94.

The Spanish texts in `tables.es.json` are an irondroid translation of those texts, under the same license.
